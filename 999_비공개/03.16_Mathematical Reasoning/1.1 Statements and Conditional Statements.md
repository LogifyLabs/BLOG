
# 1.1 Statements and Conditional Statements

> [!abstract] 핵심 요약
> **조건문($P \to Q$)**은 프로그래밍의 제어 흐름(`if-then`)과 데이터 검증의 기초 논리입니다. $P$가 참인데 $Q$가 거짓인 경우에만 전체가 거짓이 됩니다.

## 1. Know (Definitions)
* **명제 (Statement):** 참(True) 또는 거짓(False)이 명확한 문장.
* **조건문 (Conditional Statement):** $P \to Q$ ("If $P$, then $Q$")
	* **진리표 (Truth Table):**
		* $T \to F$ 만 **False** (버그 발생 상황)
		* $F \to T/F$ 는 **True** (전제가 거짓이면 결과와 무관하게 논리적으로 참 - Vacuously True)

## 2. Show (AI Connection)
* **Python Control Flow:**
	```python
	if hypothesis_P:
	    conclusion_Q()
	# P가 False면 Q는 실행되지 않지만, 코드 자체는 에러 없이 통과됨 (Vacuously True)
	```
* **데이터 무결성 (Data Integrity):**
	* 명제: "데이터가 이미지 파일이면($P$), 픽셀 값은 0~255 사이여야 한다($Q$)."
	* 검증: 이미지 파일인데($P=T$), 픽셀 값이 300이다($Q=F$) -> **데이터 오류(False)**.

## 3. Practice (Hand-Solved)
> [!question] 예제: $P \to Q$의 대우(Contrapositive) 구하기
> * **명제:** "모델이 과적합(Overfit)되었다면, 테스트 오차가 높다."
> * **대우 ($\neg Q \to \neg P$):** "테스트 오차가 높지 않다면(낮다면), 모델은 과적합되지 않았다."
> * **활용:** 모델 성능 진단 시 역방향 추론에 사용.
