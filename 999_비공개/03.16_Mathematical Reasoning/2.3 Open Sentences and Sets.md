
# 2.3 Open Sentences and Sets

> [!abstract] 핵심 요약
> **열린 문장($P(x)$)**은 변수 $x$에 따라 참/거짓이 달라지는 문장입니다. 이를 참으로 만드는 $x$들의 모임이 **진리 집합(Truth Set)**이며, 이는 데이터베이스의 **쿼리(Query)** 결과와 같습니다.

## 1. Know (Definitions)
* **열린 문장 (Open Sentence):** 변수 $x$를 포함하며, $x$가 결정되어야만 명제가 되는 문장. (예: $x^2 - 4 = 0$)
* **전체 집합 (Universal Set, $U$):** 변수 $x$가 선택될 수 있는 전체 범위.
* **진리 집합 (Truth Set):** $\{x \in U \mid P(x) \text{ is true}\}$.

## 2. Show (AI Connection)
* **Data Querying:**
    * $U$: 전체 데이터셋 (DataFrame)
    * $P(x)$: 필터링 조건 (예: `accuracy > 0.9`)
    * Truth Set: 조건을 만족하는 데이터 행(Row)들.
* **방정식의 해(Solution):** $f(x) = 0$을 만족하는 $x$를 찾는 것은 열린 문장의 진리 집합을 찾는 것입니다.

## 3. Practice (Python Pandas)
```python
import pandas as pd

# U: 전체 집합
df = pd.DataFrame({'model': ['A', 'B', 'C'], 'acc': [0.85, 0.92, 0.78]})

# P(x): accuracy > 0.9 (열린 문장)
condition = df['acc'] > 0.9 

# Truth Set 구하기
best_models = df[condition]
print(best_models) 
# 결과: Model B (진리 집합의 원소)
```
