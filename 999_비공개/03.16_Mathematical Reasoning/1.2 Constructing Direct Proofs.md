
# 1.2 Constructing Direct Proofs

> [!abstract] 핵심 요약
> **직접 증명**은 가정($P$)에서 시작하여 정의와 정리를 통해 결론($Q$)을 도출하는 과정입니다. 이는 알고리즘이 의도한 대로 작동함을 보장하는 **정당성(Correctness)** 검증과 같습니다.

## 1. Know (Definitions)
* **구조:** $P \implies \dots \implies Q$
* **짝수/홀수 정의 (Parity):**
	* Even: $n = 2k$ ($k \in \mathbb{Z}$)
	* Odd: $n = 2k + 1$ ($k \in \mathbb{Z}$)

## 2. Show (AI Connection)
* **알고리즘 설계:** 입력 데이터의 전제 조건(Pre-condition)이 맞다면, 출력 데이터(Post-condition)는 반드시 특정 형태여야 함.
* **Feature Engineering:**
	* "모든 입력 픽셀을 2배 하면($P$), 이미지의 명도(Brightness)는 2배가 된다($Q$)." -> 이를 수식으로 증명하고 코드로 구현.

## 3. Practice (Hand-Solved)
> [!example] 증명: 두 홀수의 곱은 홀수인가?
> * **가정 (Know):** $m = 2k+1, n = 2j+1$
> * **전개:**
>   $m \cdot n = (2k+1)(2j+1)$
>   $= 4kj + 2k + 2j + 1$
>   $= 2(2kj + k + j) + 1$
> * **결론 (Show):** $2(\text{integer}) + 1$ 형태이므로 홀수이다.
> * **AI 응용:** 합성곱(Convolution) 연산 시 커널 사이즈(홀수/짝수)에 따른 출력 차원 계산 검증.
