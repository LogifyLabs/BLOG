
# 2.1 Statements and Logical Operators

> [!abstract] 핵심 요약
> **논리 연산자(AND, OR, NOT)**는 복잡한 조건을 결합하여 새로운 명제를 만드는 도구입니다. AI에서는 데이터 필터링과 모델의 결정 경계(Decision Boundary)를 형성하는 기초가 됩니다.

## 1. Know (Definitions)
* **논리 연산자 (Logical Operators):**
    * **Conjunction ($\land$):** $P \land Q$ ("P and Q"). 둘 다 참일 때만 참.
    * **Disjunction ($\lor$):** $P \lor Q$ ("P or Q"). 둘 중 하나라도 참이면 참. (Inclusive OR)
    * **Negation ($\neg$):** $\neg P$ ("not P"). 참/거짓을 반전.
* **항진명제 (Tautology):** 항상 참인 명제 (예: $P \lor \neg P$).
* **모순 (Contradiction):** 항상 거짓인 명제 (예: $P \land \neg P$).

## 2. Show (AI Connection)
* **Boolean Indexing:** Pandas나 Numpy에서 데이터를 추출할 때 논리 연산자가 필수적입니다.
    * `data[(age > 20) & (gender == 'F')]` ($P \land Q$)
* **Bitwise Operations:** 이미지 마스킹(Masking) 처리 시 픽셀 단위의 논리 연산을 수행합니다.

## 3. Practice (Python Implementation)

```python
def check_logic(p: bool, q: bool):
    # Truth Table 구현
    and_op = p and q      # Conjunction
    or_op = p or q        # Disjunction
    not_p = not p         # Negation
    
    print(f"P={p}, Q={q} | AND={and_op}, OR={or_op}, NOT P={not_p}")

# 테스트
check_logic(True, False)
```
