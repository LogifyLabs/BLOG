### 정의

**사용자 인터페이스 (UI)**는 소프트웨어 시스템과 사용자 간의 **상호작용을 매개**하는 모든 시각적, 청각적, 조작적 요소들의 총체입니다. 이는 시스템의 추상적인 **개념 (Concepts)**을 사용자의 감각에 전달하고, 사용자가 시스템의 **개념의 액션 (Action)**을 수행할 수 있도록 해주는 구체적인 **매핑 도구**입니다.

---

### CBD와의 관계:

- **개념의 표현:** UI는 **개념 계층**에서 정의된 **개념의 구조 (Concept Structure)**를 **물리 및 언어 계층**에서 구체화하는 수단입니다.     
    
- **개념의 매핑 (Concept Mapping)**의 대상: 추상적인 **개념의 상태 (State)**와 **개념의 액션 (Action)**이 UI 요소(버튼, 아이콘, 텍스트)에 명확하게 연결되어야 **사용성 (Usability)**이 확보됩니다.     
    

---

### 핵심 역할:

UI는 시스템의 논리적 본질인 **개념**을 사용자에게 **직관적 사용 (Intuitive Use)**이 가능하도록 전달해야 합니다. 개념과 UI 간의 불일치는 심각한 **사용자 경험 (UX)** 문제를 야기합니다.
